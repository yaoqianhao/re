**方法局限（必须同读，防止过度解读）**

亮度梯度法在本夹具上灵敏度有限：地形是平滑 Lambertian 着色、无贴图，垂直方向明暗变化只有约 0.1 灰阶/行。
实测把 `seam_04` 接缝下侧整体下移 1 / 2 / 3 px 合成台阶后，统计输出仍是 peak 中位 0.0、平整列占比 100%
（即该方法抓不到几像素级台阶）；按各机位实测着色斜率反算，修复前那 7.30 m 错位在多数机位只对应
0.1~0.9 灰阶的突变，只有 `seam_02`（≈3.3）和 `seam_09`（≈12.2）两个机位足够显眼。
因此本节把结论分工写清：**「无透光裂缝」由洋红探针定量给出（灵敏、可自检）；「无台阶错位」在本批截图上只主张
「肉眼不可辨」，等量的严格证明由 `tests/mesh.rs` 19 条判据承担（顶点逐位相等，不存在亚像素容差）。**
不把梯度统计当作「错位 = 0」的定量证据。
